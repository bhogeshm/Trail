SCHOOL MILES - PREMIERE PRO EDIT PACKAGE
========================================

This folder contains the whole edit as a Premiere Pro sequence.
Sequence: 1080 x 1920 (vertical), 30 fps, 26.8 s, stereo 48 kHz.

1) UNZIP
   Unzip ALL parts (Part1, Part2, Part3) into the SAME folder so that you get:
       SchoolMiles_Premiere/
           SchoolMiles.xml
           media/   (every clip, title, graphic and the music)
           fonts/

2) OPEN IN PREMIERE PRO
   - Open Premiere Pro, create a new project (File > New > Project), save it
     anywhere you like (this becomes your .prproj).
   - File > Import...  choose  SchoolMiles.xml
   - A bin appears with the sequence "School Miles - Final Edit". Double-click it.
   - If Premiere shows "Link Media": click Locate, open the media folder,
     select the file it asks for and press OK. With "Relink others automatically"
     ticked, every other file is found at once.
   - Save the project (Ctrl+S / Cmd+S). You now have your .prproj.

3) WHAT IS ON THE TIMELINE
   V6  CSR end card          (dissolves in at 22.5s, fades to black at 26.2s)
   V5  Animated titles       (transparent .mov files, one per title)
   V4  Navy dim 72%          (behind the SCHOOL MILES lockup)
   V3  Scrim                 (soft bottom gradient + vignette so text reads)
   V2  Campaign banner       (blur baked in, dissolves in at 19.6s)
   V1  Footage cuts          (hard cuts on the beat, slow push-in keyframes)
   A1  Original score        (stomp + clap, piano, strings - royalty free)

   Push-ins, dissolves and fades are ordinary Scale / Opacity keyframes in
   Effect Controls, so you can change or delete them.

4) EDITING THE TEXT
   The titles are pre-animated graphics (transparent video). To change wording:
   - Install the fonts in the fonts/ folder (Montserrat Medium / Bold / ExtraBold).
   - Disable the title on V5, then use the Type tool (T) or Essential Graphics
     to create your text. Style used:
       Headline: Montserrat ExtraBold, white, ~104 px (phrases ~80 px)
       Subline:  Montserrat Medium, white 92%, ~38 px, tracking +60
       Accent:   red bar #D6232F, 96 x 6 px, above the headline
       Position: left margin 88 px, text bottom ~360 px above frame bottom

5) FOOTAGE NOTES
   The clips c01-c13 are cut from your upload with the light-leak / glitch
   transitions removed and a gentle slow-motion (about 0.85x) already applied,
   each with ~0.4 s extra at the end for trimming. The full untouched upload
   is also included as media/original_upload.mp4 if you want other moments.
